# AmarGazipur — cPanel শেয়ার্ড হোস্টিং ইনস্টলেশন গাইড (বাংলা)

## ধাপ ১: ZIP ফাইল আপলোড ও Extract করা
1. cPanel -> **File Manager** খুলে আপনার সাবডোমেইন ফোল্ডারে `AmarGazipur_Full_Website.zip` আপলোড করে **Extract** করুন।

## ধাপ ২: MySQL ডেটাবেস তৈরি ও `config/database.php` এডিট করা
1. cPanel -> **MySQL® Databases** থেকে একটি ডেটাবেস ও ইউজার তৈরি করুন এবং **ALL PRIVILEGES** দিন।
2. File Manager-এ **`config/database.php`** ফাইলটি **Edit** করুন এবং উপরের ৪টি লাইনে আপনার ডেটাবেসের তথ্য বসান:
   - `DB_HOST`: সাধারণত `localhost`
   - `DB_NAME`: আপনার ডেটাবেসের নাম
   - `DB_USER`: আপনার ডেটাবেস ইউজারনেম
   - `DB_PASS`: আপনার ডেটাবেস পাসওয়ার্ড
3. ফাইলটি Save করুন।

## ধাপ ৩: ওয়েবসাইট ভিজিট ও অ্যাডমিন অ্যাকাউন্ট তৈরি
1. ব্রাউজারে আপনার সাবডোমেইন ভিজিট করলেই ডেটাবেস টেবিল স্বয়ংক্রিয়ভাবে তৈরি হয়ে ওয়েবসাইট চালু হয়ে যাবে।
2. এরপর `https://yourdomain.com/admin` ভিজিট করে আপনার প্রথম **Admin অ্যাকাউন্ট** তৈরি করুন।
